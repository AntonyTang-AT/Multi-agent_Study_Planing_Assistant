# 样例账号

短用户名 + 短密码，方便现场手输（登录页也可点芯片一键填入）。

登录后按账号灌入各自的计划、作答、提醒与个人学习画像。

| 用户名 | 密码 | 角色 | 人物与场景 |
|--------|------|------|------------|
| `math` | `demo` | 学生 | 林清夏 · 高数期末冲刺；今晚连续性证明超时待调整 |
| `phys` | `demo` | 学生 | 周予安 · 大物力学跟课；斜面题漏写摩擦 |
| `catch` | `demo` | 学生 | 陈可 · 连续两天未练后的短任务恢复 |
| `cs` | `demo` | 学生 | 江予澈 · 计概 Python；今晚沙箱+洛谷超时待确认 + 代码助教 |
| `admin` | `admin` | 管理 | 全站学习概况 |

种子命令：

```bash
cd backend
python -m scripts.seed_demo_accounts
```

建议体验路径：

1. `math` → 首页超时提醒 → 计划页选择调整方式 → 轨迹看极限/证明掌握度
2. `phys` → 计划时间线 → 提醒里的摩擦力问题 → 轨迹错因
3. `catch` → 节奏提醒 → 15 分钟热身计划 → 对话询问「最少要完成什么」
4. `cs` → 计划页确认今晚安排 → 练习台跑沙箱自测 → 右侧助教解读报错
5. `admin` → 管理看板
