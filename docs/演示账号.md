# 演示账号

短用户名 + 短密码，方便现场手输（登录页也可点芯片一键填入）。

登录后会按账号从后端灌入**各自**的计划 / 黑板 / 作答痕迹，界面不再共用同一份空演示态。

| 用户名 | 密码 | 角色 | 个性化内容 |
|--------|------|------|------------|
| `math` | `demo` | 学生 | 高数期末计划；第 3 天超时 **conflict**；3 次作答（错/对/弃答）；开放冲突黑板 |
| `phys` | `demo` | 学生 | 大物跟课计划（已通过审计）；4 次作答；开放 **challenge** 黑板 |
| `catch` | `demo` | 学生 | 恢复计划；时间跳跃 +3；主动 **intervention**；稀疏作答 |
| `admin` | `admin` | 管理员 | `/admin` 全站统计 |

种子命令：

```bash
cd backend
python -m scripts.seed_demo_accounts
```

建议演示路径：

1. `math` → 首页冲突提示 → 学习计划裁决 → 黑板
2. `phys` → 计划时间线 → 轨迹错因 → 黑板质疑
3. `catch` → 干预卡片 → 黑板 → 短任务计划
4. `admin` → 管理看板分布
