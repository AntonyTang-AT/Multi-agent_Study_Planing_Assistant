## 二、连续的三级定义

**点连续**：$\lim\limits_{x\to x_0}f(x)=f(x_0)$。等价于三条同时成立：
1. $f(x_0)$ 有定义；
2. $\lim\limits_{x\to x_0}f(x)$ 存在；
3. 两者相等。

**左/右连续**：$f(x_0^{-})=f(x_0)$ 为左连续，$f(x_0^{+})=f(x_0)$ 为右连续。
$f$ 在 $x_0$ 连续 $\iff$ 既左连续又右连续。

**区间连续**：在 $(a,b)$ 内每点连续；在端点处指单侧连续。

## 三、间断点分类（必考，一张表定生死）

设 $x_0$ 是 $f$ 的间断点，看**左右极限是否存在**：

| 类型 | 判据 | 子类 | 例子 |
|---|---|---|---|
| **第一类**（左右极限都存在） | $f(x_0^-)$、$f(x_0^+)$ 都存在 | 可去：两者相等但 $\ne f(x_0)$ 或无定义 | $\frac{\sin x}{x}$ 在 $x=0$ |
| | | 跳跃：两者不相等 | $\frac{\lvert x\rvert}{x}$ 在 $x=0$ |
| **第二类**（至少一侧不存在） | 至少一侧极限不存在 | 无穷：极限为 $\infty$ | $\frac1x$ 在 $x=0$ |
| | | 振荡：来回摆动不趋于定值 | $\sin\frac1x$ 在 $x=0$ |

**记忆口诀**：先看左右极限"有没有"，再看"等不等"。

## 四、闭区间上连续函数的三大定理

设 $f\in C[a,b]$：

1. **最值定理**：$f$ 在 $[a,b]$ 上必取到最大值 $M$ 与最小值 $m$。
2. **介值定理**：$\forall \mu\in[m,M]$，$\exists \xi\in[a,b]$ 使 $f(\xi)=\mu$。
3. **零点定理**：若 $f(a)\cdot f(b)<0$，则 $\exists\xi\in(a,b)$ 使 $f(\xi)=0$。

**注意三条前提**：闭区间、连续、$f(a)f(b)<0$（零点定理）。开区间或含间断点时结论不成立。

## 五、常考题型

### 题型 1：判断间断点类型（最高频）

**套路**：找出无定义点或分段点 → 分别算左右极限 → 按表归类。

**例**：$f(x)=\dfrac{x^{2}-1}{x^{2}-3x+2}$ 的间断点。
分母零点 $x=1,2$。
- $x=1$：$\lim\limits_{x\to1}\dfrac{(x-1)(x+1)}{(x-1)(x-2)}=\dfrac{2}{-1}=-2$，极限存在 → **可去间断点**。
- $x=2$：$\lim\limits_{x\to2}\dfrac{x+1}{x-2}=\infty$ → **无穷间断点（第二类）**。

### 题型 2：求参数使函数连续

**套路**：分段点处令左极限 = 右极限 = 函数值，解方程。

**例**：$f(x)=\begin{cases}\dfrac{e^{x}-1}{x},&x\ne0\\ a,&x=0\end{cases}$ 在 $x=0$ 连续，求 $a$。
$$\lim_{x\to0}\frac{e^{x}-1}{x}=1\ \Rightarrow\ a=1.$$

### 题型 3：用零点定理证明方程有根

**套路**：构造 $F(x)$ = 方程移项后的左边 → 找两点使 $F$ 异号 → 引用零点定理。

**例**：证明 $x^{3}+x-1=0$ 在 $(0,1)$ 内有且仅有一个实根。
令 $F(x)=x^{3}+x-1$，$F(0)=-1<0$，$F(1)=1>0$，由零点定理 $\exists\xi\in(0,1)$ 使 $F(\xi)=0$。
唯一性：$F'(x)=3x^{2}+1>0$ 恒成立，$F$ 严格单调递增，故根唯一。

### 题型 4：连续但不可导（陷阱题）

**例**：$f(x)=\dfrac{x^{2}\sin\frac1x}{\sin x}\ (x\ne0)$，$f(0)=0$。
连续：$|f(x)|\le\dfrac{x^{2}}{|\sin x|}\le2|x|\to0$ ✓。
可导性：差商 $=\dfrac{x}{\sin x}\sin\dfrac1x$，前因子 $\to1$，后因子振荡。取 $x_n=\frac{1}{n\pi}$ 得 0，取 $x_n=\frac{1}{2n\pi+\pi/2}$ 得 1，两子列不同 → **不可导**。

## 六、易错点

1. **把"极限存在"当成"连续"**。可去间断点处极限存在但不连续（或函数值不等）。
2. **分段点只看一侧**。$f(x)=\begin{cases}x,&x<0\\ x+1,&x\ge0\end{cases}$ 在 0 处右连续但左不连续，故不连续。
3. **零点定理忽略"闭区间 + 连续"**。$f(x)=\frac1x$ 在 $[-1,1]$ 上 $f(-1)f(1)<0$ 却无根，因为不连续。
4. **振荡间断点误判为无穷**。$\sin\frac1x$ 在 0 附近有界但无极限，属振荡，不是无穷。
5. **证"唯一性"时忘记说明单调**。零点定理只保证存在，唯一性要另证。
