## 二、两个重要极限与推广

$$\lim_{x\to0}\frac{\sin x}{x}=1
\qquad\Longrightarrow\qquad
\lim_{\square\to0}\frac{\sin\square}{\square}=1$$

$$\lim_{x\to\infty}\left(1+\frac1x\right)^{x}=e
\qquad\Longrightarrow\qquad
\lim_{\square\to0}(1+\square)^{1/\square}=e$$

**三条常用变形**
$$\lim_{x\to0}\frac{\tan x}{x}=1,\qquad
\lim_{x\to0}\frac{1-\cos x}{x^{2}}=\frac12,\qquad
\lim_{x\to0}\frac{\arcsin x}{x}=1.$$

## 三、等价无穷小表（$x\to0$，必须背下来）

$$\sin x\sim x,\quad \tan x\sim x,\quad \arcsin x\sim x,\quad \arctan x\sim x,$$
$$1-\cos x\sim\frac{x^{2}}{2},\quad e^{x}-1\sim x,\quad \ln(1+x)\sim x,$$
$$(1+x)^{\alpha}-1\sim\alpha x,\quad a^{x}-1\sim x\ln a,\quad x-\sin x\sim\frac{x^{3}}{6},\quad \tan x-x\sim\frac{x^{3}}{3}.$$

**使用铁律**：等价替换只能用于**乘除因子**，加减项里替换会丢高阶项导致错误。
反例：$\lim\limits_{x\to0}\dfrac{\tan x-\sin x}{x^{3}}$，若把 $\tan x$、$\sin x$ 都替换成 $x$ 得 0；正确做法是先提出 $\tan x(1-\cos x)$ 或用泰勒，答案 $\dfrac12$。

## 四、七种未定式与对应打法

| 型 | 特征 | 打法 |
|---|---|---|
| $\frac00$ | 分子分母同趋于 0 | 因式分解约去零因子 / 等价替换 / 洛必达 |
| $\frac{\infty}{\infty}$ | 同趋于 $\infty$ | 同除最高次幂 / 洛必达 |
| $\infty-\infty$ | 两项相减 | 通分或有理化，化为 $\frac00$ |
| $0\cdot\infty$ | 一零一无穷 | 把一个因子写成倒数，化为 $\frac00$ 或 $\frac{\infty}{\infty}$ |
| $1^{\infty}$ | 底趋 1、指数趋 $\infty$ | 用 $\lim u^{v}=e^{\lim v(u-1)}$ 或取对数 |
| $0^{0}$ | 底、指数同趋 0 | 取对数 |
| $\infty^{0}$ | 底趋 $\infty$、指数趋 0 | 取对数 |

**$1^{\infty}$ 快捷公式**
$$\lim u(x)^{v(x)}=\exp\left[\lim v(x)\bigl(u(x)-1\bigr)\right].$$

## 五、常考题型

### 题型 1：$\frac00$ 型 + 等价替换

**例**：$\lim\limits_{x\to0}\dfrac{\ln(1+3x)}{\sin 2x}=\lim\limits_{x\to0}\dfrac{3x}{2x}=\dfrac32$。

### 题型 2：$\infty-\infty$ 型（有理化）

**例**：$\lim\limits_{x\to+\infty}\left(\sqrt{x^{2}+x}-x\right)=\lim\limits_{x\to+\infty}\dfrac{x}{\sqrt{x^{2}+x}+x}=\dfrac12$。

### 题型 3：$1^{\infty}$ 型

**例**：$\lim\limits_{x\to0^{+}}\left(\dfrac1x\right)^{\tan x}$。取对数：$\ln L=-\tan x\ln x\to0$，故 $L=1$。

**注意**：不能写"$\infty^{0}=1$"，必须说明 $x\ln x\to0$。

### 题型 4：递推数列（单调有界准则）

**例**：$x_{1}=\sqrt2,\ x_{n+1}=\sqrt{2+x_{n}}$。
先证有界：归纳得 $x_n<2$；再证单调：$x_{n+1}-x_n=\frac{2+x_n-x_n^2}{\sqrt{2+x_n}+x_n}>0$（因 $x_n<2$）。
故收敛，设极限为 $A$，由 $A=\sqrt{2+A}$ 得 $A=2$。

### 题型 5：已知极限反求参数

**例**：若 $\lim\limits_{x\to\infty}\left(\dfrac{x^{2}+1}{x+1}-ax-b\right)=0$，求 $a,b$。
通分得 $\dfrac{(1-a)x^{2}-(a+b)x+(1-b)}{x+1}\to0$，要求分子次数低于分母：
$$1-a=0,\quad a+b=0\ \Rightarrow\ a=1,\ b=-1.$$

## 六、易错点

1. **在加减项里用等价无穷小**。$\tan x-\sin x$ 直接换 $x-x=0$ 是经典错误。
2. **$1^{\infty}$ 直接写 1**。$1^{\infty}$ 是未定式，必须算。
3. **忘记 $x\to0^{-}$ 与 $x\to0^{+}$ 可能不同**。含 $\sqrt{x}$、$e^{1/x}$、$\arctan\frac1x$、$|x|$ 的极限必须分左右。
4. **$\lim(f+g)=\lim f+\lim g$ 的前提是两个极限都存在**。拆开后出现 $\infty-\infty$ 就是违规操作。
5. **有界量乘无穷小才为 0**。$\sin\frac1x$ 有界，但乘 $\frac{x}{\sin x}\to1$ 时不能说"有界量"就完了。
