## 二、平动 ↔ 转动 对照表（背这张表等于背全章）

| 平动 | 转动 | 关系 |
|---|---|---|
| 位移 $x$ | 角位移 $\theta$ | $\theta=x/R$ |
| 速度 $v$ | 角速度 $\omega$ | $v=\omega R$ |
| 加速度 $a$ | 角加速度 $\beta$ | $a=\beta R$ |
| 质量 $m$ | 转动惯量 $I$ | $I=\sum m_ir_i^{2}$ |
| 力 $F$ | 力矩 $M=Fr\sin\theta$ | |
| **$F=ma$** | **$M=I\beta$** | 转动定律 |
| 动量 $p=mv$ | 角动量 $L=I\omega$ | |
| 动能 $\frac12mv^{2}$ | $\frac12I\omega^{2}$ | |
| 功 $W=\int F\mathrm{d}x$ | $W=\int M\mathrm{d}\theta$ | |

## 三、常用转动惯量（必背）

| 刚体 | 转轴 | $I$ |
|---|---|---|
| 细杆（长 $l$，质量 $m$） | 过中心垂直杆 | $\dfrac{1}{12}ml^{2}$ |
| 细杆 | 过端点垂直杆 | $\dfrac13ml^{2}$ |
| 圆盘/圆柱（半径 $R$） | 中心轴 | $\dfrac12mR^{2}$ |
| 圆环/薄圆筒 | 中心轴 | $mR^{2}$ |
| 球体（半径 $R$） | 直径 | $\dfrac25mR^{2}$ |
| 球壳 | 直径 | $\dfrac23mR^{2}$ |

**平行轴定理**：$I=I_C+md^{2}$（$I_C$ 为过质心平行轴的转动惯量）。

## 四、核心公式

$$M=I\beta,\qquad I=\sum_im_ir_i^{2}=\int r^{2}\mathrm{d}m,$$
$$E_k=\frac12I\omega^{2},\qquad L=I\omega,\qquad M=\frac{\mathrm{d}L}{\mathrm{d}t}.$$
**刚体机械能守恒**（只有重力做功时）：$\frac12I\omega^{2}+mgh_C=\text{const}$。

## 五、常考题型

### 题型 1：定轴转动定律（最高频）

**例**：细杆长 $L$、质量 $m$，一端有光滑固定轴，初始水平静止释放，求转到竖直位置时的角速度。
机械能守恒：$mg\frac L2=\frac12I\omega^{2}$，$I=\frac13mL^{2}$。
$$\omega=\sqrt{\frac{3g}{L}}.$$
角加速度（水平位置时）：$M=mg\frac L2=I\beta\Rightarrow\beta=\frac{3g}{2L}$。

### 题型 2：滑轮 + 挂重（联立）

**例**：圆盘滑轮 $M=4$ kg、$R=0.5$ m，挂 $m=2$ kg 物体，求 $a$ 与 $T$（$g=9.8$）。
$$\begin{cases}mg-T=ma\\ TR=\frac12MR^{2}\cdot\frac{a}{R}\Rightarrow T=\frac12Ma\end{cases}$$
$$\Rightarrow a=\frac{2mg}{2m+M}=\frac{2\times2\times9.8}{4+4}=4.9\ \mathrm{m/s^{2}},\quad T=\frac{Mmg}{2m+M}=9.8\ \mathrm{N}.$$
**易错**：把滑轮当无质量得 $a=g$、$T=0$，与实际不符。

### 题型 3：角动量守恒（人体/转台）

**例**：转台（$I_1$）以 $\omega_1$ 转动，人把哑铃由 $r_1$ 收到 $r_2$，求新角速度。
$$(I_1+mr_1^{2})\omega_1=(I_1+mr_2^{2})\omega_2.$$
**动能增加**，来自人做的功。

### 题型 4：刚体碰撞（角动量守恒）

**例**：子弹 $m$、速率 $v$ 垂直击中静止细杆（$M,L$）下端并嵌入，求碰后角速度（杆可绕上端转）。
角动量守恒（对轴上端）：$mvL=\left(\frac13ML^{2}+mL^{2}\right)\omega$。

## 六、易错点

1. **力矩漏 $\sin\theta$**。$M=Fr\sin\theta$，力臂是**轴到力作用线的垂直距离**。
2. **转动惯量的轴搞错**。细杆过中心与过端点的 $I$ 差 4 倍。
3. **滑轮问题忽略滑轮转动惯量**，导致 $T$ 两侧相等（实际不等）。
4. **角动量守恒时选错参考点**。必须对**同一固定点（或轴）**取角动量。
5. **刚体碰撞用动量守恒**。有固定轴时动量不守恒（轴有反力），只能用角动量守恒。
6. **$E_k=\frac12I\omega^2$ 与 $\frac12mv^2$ 混用**。转动惯量对应的是绕轴的转动动能。
